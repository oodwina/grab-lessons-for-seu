## 安装与使用

1. 在 Tampermonkey 中用本仓库的 v3.5.0 文件替换已安装脚本，保存并只启用一个版本。
2. 在同一浏览器连接校园网／aTrust，登录选课首页，进入具体轮次的课程列表后刷新。助手只在 `/xsxk/elective/grablessons` 页面运行。
3. 展开教学班，点击“添加”建立本地待选列表；也可输入“课程号＋班序号”，用空格、逗号或换行分隔，按 Enter 查询。
4. 检查列表后点击“抢课”。运行期间可通过“停止抢课”结束后续调度。

悬浮入口使用独立的 40 × 40 像素样式和内嵌日历图标，支持鼠标点击、拖动和键盘激活。

### 发送与搜索设置

- 支持单次／循环、同步／异步、单个／分组模式。
- 同步和异步的单个发送间隔分别保存，范围为 1–60000 ms。
- 在“扩展设置 → 更多 → 每组课程数”填写正整数。每组按所填数量发送，旧配置缺少该字段时默认填入 3；分组间隔范围为 1000–60000 ms。
- “更多”中的每组数量设置不依赖搜索开关。启用搜索后，可配置每页数量与翻页延迟；翻页间隔最低 1000 ms。
- 同一教学班的未决请求不会重复提交。下一轮会等待上一轮在途任务结束，因此设置间隔并不保证实际发送时刻。

## 队列结果与适用范围

普通选课通过 `/elective/clazz/add` 入队，业务响应 200 只表示请求被接收。WebSocket 的 `operationType=1` 返回选课最终结果；`operationType=2` 返回退课最终结果。

助手收到最终成功推送，或在 `/elective/select` 的普通已选记录中找到对应教学班后，才移除本地待选项。结果无法确认时显示“待核实”并停止重复提交。停止、刷新或删除本地待选项不能撤销服务器已接收的任务。

`/elective/deselect` 是退课日志查询接口，真正提交退课的是 `/elective/clazz/del`。本版不执行自动退课。志愿轮次、实验班、教材等需要额外选择的流程，请使用官网完成。

本次核对包括实站课程卡片结构、查询请求路径和当前官方前端源码；没有实际提交选课或退课，也没有完整 HAR 或真实选退课最终 WebSocket 帧。前端证据不能证明后端队列采用 FIFO 或保证名额分配。

## 本地构建与测试

安装 Node.js 和 pnpm 后执行：

```powershell
pnpm install --frozen-lockfile --ignore-scripts
node tools/build.cjs
node --test tests/*.test.cjs
node --check '东南大学抢课助手修改版-3.5.0.user.js'
```

- `src/seu-core.js`：协议状态与调度。
- `src/compat-runtime.js`：官网页面、请求与 WebSocket 对接。
- `src/legacy-ui.js`：沿用并适配的 UI。
- `tools/build.cjs`：将以上源码组合成根目录的可安装脚本，不需要另备 v3.4.1 文件。

修改源文件后应重新构建，不要只修改生成文件。本地配置沿用 `july` 存储键，课程提交凭据从当前会话重新获取。

32 项测试覆盖队列结果、推送竞态、301 确认、停止、配置恢复、可配置分组、1 ms 间隔、课程卡片与悬浮入口。离线测试不能替代真实账号的完整验收。上游的历史行为记录见 [legacy-behavior-spec.md](https://github.com/julymiaw/grab-lessons-for-seu/blob/main/docs/legacy-behavior-spec.md)。
