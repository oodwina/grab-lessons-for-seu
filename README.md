# 东南大学选课助手 3.5.0

基于原 3.4.1 适配 2026-09-23 检查到的官网页面与队列协议，保留原面板布局。

版本 **3.5.0**，作者 **july, nada**。悬浮入口使用独立的 40 × 40 像素样式和内嵌日历 SVG，保留左侧初始位置、鼠标点击开关和拖动；也可聚焦后用键盘激活。图标不再依赖官网 CSS 或图标字体。

## 安装

1. 将 `东南大学抢课助手修改版-3.5.0.user.js` 的完整内容粘贴到 Tampermonkey 脚本编辑器，保存并启用；停用旧版，确保只运行一个版本。
2. 在该浏览器连接校园网／aTrust，登录选课首页，进入具体轮次的课程列表后刷新。助手只在 `/xsxk/elective/grablessons` 页面运行。
3. 展开课程教学班，点“添加”建立本地待选列表，或输入“课程号＋班序号”并按 Enter；检查列表后点原“抢课”按钮。

单个发送模式的时间间隔最低可填 **1 ms**，同步和异步分别保存。在“扩展设置 → 更多 → 每组课程数”填写正整数，确认后选择“分组发送”，每组按该数量执行；关闭搜索功能时也可使用此设置。首次使用或旧配置没有该字段时填入 3，可自行修改。分组间隔仍最低 1000 ms。

入队后显示“排队中”；最终推送或官方已选记录确认成功后，才从待选列表移除。出现“待核实”时会保留课程并阻止重复提交。点击停止或删除本地项，不能取消服务器已经接收的队列任务。

自动提交支持普通选课轮次；志愿、实验班和教材等需要额外选择的流程，请使用官网完成。本版没有自动退课功能。

普通选课通过 `/elective/clazz/add` 入队，WebSocket 的 `operationType=1` 返回选课最终结果；`operationType=2` 返回退课最终结果。`/elective/select` 查询普通已选课程，`/elective/deselect` 查询退课日志，真正提交退课的是 `/elective/clazz/del`。前端证据不能证明后端队列采用 FIFO 或保证名额分配。

## 开发

Node.js 环境中安装开发依赖后构建、测试：

```powershell
pnpm install --frozen-lockfile --ignore-scripts
node tools/build.cjs
node --test tests/*.test.cjs
node --check '东南大学抢课助手修改版-3.5.0.user.js'
```

`src/seu-core.js` 实现协议状态与调度，`src/compat-runtime.js` 对接页面，`src/legacy-ui.js` 保存沿用并适配的 UI。`tools/build.cjs` 将三部分组合成 3.5.0，不需要另备 3.4.1 文件。修改源文件后应重新构建，不要只改生成文件。

本地数据仍使用旧版的 `july` 存储键；新版会清除旧设置中的 token，并且不持久化 `secretVal`。请求凭据仅从当前官网登录会话和课程查询结果取得。
